# Multi-Stage AI Workflow Across UX Types

## Scenario

Create a workflow that solves a problem by chaining outputs between at least
two different AI UX types.

## Learning objectives

- Design an AI workflow spanning different UX types.
- Integrate the output of one AI tool into another.
- Keep the workflow adaptable to different providers.

## Required workflow

1. Select a problem that can be split into multiple stages.
2. Choose two AI tools from different UX categories.
3. Make the output from the first tool the input for the second.
4. Implement and test the workflow end-to-end.
5. Document the workflow with a diagram and clear step-by-step notes.

## Expected deliverables

- A working workflow across two UX types.
- A workflow diagram.
- Written documentation.

## Evaluation

| Criterion | Weight | Requirement |
| --- | ---: | --- |
| Functionality | 40% | The workflow runs end-to-end without breaking. |
| Adaptability | 20% | The workflow minimally depends on specific tools or models. |
| Documentation | 20% | The diagram and workflow steps are clear. |
| Efficiency | 20% | The workflow meaningfully reduces manual effort. |
